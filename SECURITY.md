# Security policy

This repository is a demonstration of security controls for MCP servers. It serves fictional data and is not intended to protect real systems as-is. The [Limits](./README.md#limits) section lists what it does not cover.

## Reporting a vulnerability

If you find a way to bypass authentication, the policy, the rate limiter or the audit chain, please open a private security advisory in this repository (Security → Report a vulnerability) instead of a public issue. Include the steps to reproduce and the affected version.

I aim to acknowledge reports within 7 days.
